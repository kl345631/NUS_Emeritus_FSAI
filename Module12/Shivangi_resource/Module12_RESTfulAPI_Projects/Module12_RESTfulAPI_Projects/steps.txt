API : APPLICATION PROGRAMMING INTERFACE
AN API is bridge that allows two softwares application talk to each other.

YOU : CUSTOMER
KITCHEN : SERVER/DATABASE
WAITER: API

API hides internal logic
API exposes only what is allowed
API uses requests & responses

RESTful Web Services
REST-Representational State Transfer 

A web service that follows REST Rules to expose APIs over http

SOAP -> OLD
REST -> SIMPLE, LIGHTWEIGHT, FAST, WEB-FRIENDLY

GET, POST, PUT, DELETE

REST ? 
 Uses URLs for resources.
 Uses HTTP methods
 Stateless(server doesn't remember client)
 Uses JSON max
